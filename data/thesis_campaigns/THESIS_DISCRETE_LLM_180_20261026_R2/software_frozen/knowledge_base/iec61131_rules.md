# Reglas IEC 61131-3

- El lenguaje Structured Text se usa para expresar lógica secuencial, temporizadores, contadores y asignaciones.
- Los temporizadores deben usar literales TIME con formato IEC como `T#5s`, `T#1m` o `T#100ms`.
- Los programas PLC deben declarar variables antes de usarlas.
- Las funciones de seguridad deben tener precedencia explícita sobre la lógica de operación.
