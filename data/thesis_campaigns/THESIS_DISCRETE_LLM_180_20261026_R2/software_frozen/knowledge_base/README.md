# Base de conocimiento local

Esta carpeta contiene resúmenes técnicos propios usados como apoyo para la interpretación semántica del agente.

Principios:

- No sustituye la validación determinística.
- No autoriza la creación de variables nuevas.
- No contiene secretos ni claves.
- Sirve únicamente para apoyar al parser LLM y a la trazabilidad experimental.
